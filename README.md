Loop Marketplace:

A student-to-student campus marketplace designed to make buying and selling
items within a college community easier.

 Features:

- Student-to-student marketplace
- Product listing and browsing
- User authentication
- Database integration
- Responsive interface

  
Tech Stack:

- HTML
- CSS
- JavaScript
- Supabase

Team Project:

This project was developed collaboratively with members of our college club
as part of a Synergy project.

- I learnt how to work with a team and improved my knowledge on backend and Teamwork
- Grateful for support from my seniors 

🎯 Purpose

The goal of Loop Marketplace is to provide students with a simple platform
to buy and sell items within their campus community.
